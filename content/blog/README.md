# Rascunhos de artigos do blog

10 artigos prontos em Markdown, focados em SEO para donos de restaurante.

## Como publicar no CMS

Cada arquivo tem um cabeçalho YAML (frontmatter) entre `---` com três campos:

- `title`  → cole no campo **Título**
- `slug`   → é a URL do post (`/blog/<slug>`); o CMS gera sozinho, mas você pode manter este
- `excerpt`→ cole no campo **Resumo**

O **corpo** do artigo é tudo que vem **depois do segundo `---`**. Cole no campo
**Conteúdo** em `/admin/blog → Novo post`. O corpo já usa `##`/`###` (não tem `#`,
porque o título fica separado) e termina com um CTA para o cadastro.

Depois é só ativar o switch **Publicado** — o post vai ao ar, entra no sitemap e
ganha a OG image automaticamente.
